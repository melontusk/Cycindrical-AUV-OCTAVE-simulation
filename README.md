# Cycindrical-AUV-OCTAVE-simulation
This is a simple simulation for a AUV comprise of 4 vectorial propulsors with a cylindrical hull. It is a way to see if the vectorial propulsion system works for the necessary trajectory that is defined in the generateTrajectory.m file.

The two main files to consider for this project are plotAUV.m and sim_code.m. sim_code is the main code to consider for the generation of data while plotAUV is the main code to consider for the animation of the drone. In sim_code.m the last lines are there to plot the relevant data that is interesting to consider when judging the movement of the drone and its performance.
